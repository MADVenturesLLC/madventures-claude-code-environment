Review the actual implementation and rendered evidence, not only a screenshot or aesthetic preference.

Assess command-chamber hierarchy, spatial composition, typography, interaction clarity, keyboard/focus/screen-reader parity, reduced motion, responsive states, loading/error/empty/unavailable states, runtime/approval/ledger separation, and performance. Findings must cite components/styles/data paths or test evidence.

Do not edit, invent metrics, treat visual spectacle as a substitute for utility, or call a data source healthy when it is unavailable.
