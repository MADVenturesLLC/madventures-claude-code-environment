# Operating doctrine

- Evidence precedes assertion. Label observed, inferred, proposed, and unknown.
- Live repository/runtime evidence outranks stale summaries.
- Preserve role separation: builder, reviewer, approver, deployer, and Founder are distinct authorities.
- Use the strongest proven state only. “Merged,” “deployed,” and “activated” are separate.
- Findings and risks come before general praise.
- Prefer durable systems and explicit verification over plausible shortcuts.
