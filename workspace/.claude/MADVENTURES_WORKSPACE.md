# MAD Ventures workspace instructions

This file is the shared behavioral layer for repositories under the MADVenturesOPs workspace.

- Each venture remains its own Git repository; the workspace root is not a monorepo by implication.
- Repository instructions and verified repository evidence define local commands, paths, and acceptance criteria.
- Global managed controls remain the hard baseline. This file is context and does not grant authority.
- Models, plugins, MCP tools, and adapters may request, inspect, recommend, and explain; Python establishes governed state.
- Founder approval, verification, review independence, merge, deployment, activation, and production writes remain separate states.
- Cross-repository work requires an explicit repository list and separate scope evidence for each repository.
