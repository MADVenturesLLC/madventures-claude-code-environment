# FounderOS decision proposal

A decision proposal is not a ratified DEC.

## Required structure
1. **Decision question and scope**
2. **Current observed state** with repository evidence
3. **Constraints and governing authority**
4. **Options considered**, including status quo
5. **Evaluation criteria** and tradeoffs
6. **Recommended option** with confidence
7. **Consequences**, risks, reversibility, and migration
8. **Implementation conditions and verification**
9. **Supersedes/depends-on relationships**
10. **Founder approval block** left explicitly pending

Use precise state labels and dates. Do not edit the canonical decision log, assign a ratified identifier, or mark the proposal approved without Founder authorization. Store drafts only in an approved proposal location.
