# Documentation truth update

Trace every changed statement to current code, tests, configuration, runtime evidence, or ratified authority. Preserve distinctions between planned, implemented, verified, merged, deployed, and activated.

Update only the documents in scope. Keep commands copy-pasteable, paths current, examples safe, and version/date metadata consistent. Mark unavailable evidence rather than filling gaps with plausible language.

For governance documents, draft changes in the approved proposal/evidence path unless the Founder has explicitly authorized the canonical write. Never silently rewrite history or retroactively mark a condition met.

Verify links, commands, filenames, version counts, and cross-references. Report every statement that remains conditional or environment-dependent.
